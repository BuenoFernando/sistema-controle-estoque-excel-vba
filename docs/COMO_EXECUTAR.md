# ▶️ Como executar o sistema

## 📋 Pré-requisitos

Para utilizar o sistema é necessário:

* Microsoft Excel para Windows
* Suporte a macros VBA habilitado
* Arquivo do sistema em formato `.xlsm`

---

## 📥 Como abrir o sistema

1. Faça o download do arquivo `.xlsm` disponível neste repositório.
2. Abra o arquivo utilizando o Microsoft Excel.
3. Caso o Excel apresente um aviso de segurança, habilite o conteúdo/macros para permitir a execução do sistema.
4. Após a abertura, utilize o menu principal para acessar as funcionalidades disponíveis.

---

## 🖥️ Funcionalidades disponíveis

O sistema possui funcionalidades para:

* Cadastro de produtos
* Consulta de estoque
* Registro de entradas
* Registro de saídas
* Ajustes de estoque
* Histórico de movimentações
* Controle de estoque disponível
* Geração automática de códigos de produtos
* Automação de processos através de VBA

---

## ⚠️ Observações

Este projeto foi desenvolvido em Microsoft Excel utilizando VBA e possui caráter demonstrativo e de portfólio.

Recomenda-se utilizar uma cópia do arquivo para testes e evitar inserir informações reais ou sensíveis.
